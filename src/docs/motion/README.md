# 文档动效

GSAP 仅用于文档应用，不进入 `auricui` 的公开导出或组件包依赖。

- `engine.ts` 注册插件，提供统一的 OpenFilm 缓动和动态效果偏好订阅。
- `DocsHero.tsx` 编排首页展示。进入播放一次，支持重播；聚焦或操作卡片会立即结束动画，保留表单状态。
- `ComponentOverview.tsx` 使用 Flip 衔接分类筛选。切换前完成入场动画、清理上一次 Flip，再测量布局，避免快速切换留下中间样式。
- `useDocsMotion.ts` 管理路由入场、章节显现、导航指示和阅读进度。滚动容器是 `.docs-main`，不是 `window`。

扩展时从 `engine.ts` 导入 GSAP 与 `useGSAP`，限定组件的 `scope`。依赖变化用 `revertOnUpdate` 清理；事件回调中的动画用 `contextSafe` 纳入清理范围。观察器和原生事件监听也需要在卸载时移除。

内容默认可见。动效必须同时遵循系统 `prefers-reduced-motion` 和文档的动效开关；禁用时直接呈现可操作的最终状态。避免位移包含弹出菜单的预览区域，防止锚点坐标变化。中英文切换与重播不能重置用户输入。

浏览器回归重点：首次入场、重播中点击/键盘聚焦、语言切换、连续筛选、动效进行中切换减少动态效果、路由卸载、手机宽度，以及深浅主题。
