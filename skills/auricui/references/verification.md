# 高保真验证

先进行目标项目构建和类型检查，再做浏览器验证。没有运行环境时明确记录未做视觉验证。

比较时固定视口、DPR、缩放、平台字体、语言、内容和主题。来源页面能运行时截取源页面和目标的相同组件状态；无法运行来源时仅报告源码参数核对，不能把目标截图当成匹配证据。

覆盖实际使用的组件：默认、hover、focus-visible、active、disabled、selected、loading、error；弹窗打开关闭、菜单边缘定位和长列表滚动；聊天 Portal 的主题与字体。检查 Escape、外部点击、键盘操作和焦点恢复。目标产品缺少的业务场景不必创建。

逐项比较背景层次、边框透明度、圆角、字号字重行高、图标大小描边、控件高度、间距、阴影、遮罩模糊和层级。用浏览器 computed style 取值，不能只看类名。

动画比较起始、中间、结束状态及触发时机，检查 reduced-motion。截图可以做同尺寸叠加或像素差；字体抗锯齿和平台差异需解释，不人为给出没有基准的匹配百分比。

交付时说明引用的快照版本、移植范围、构建结果、视觉验证条件及尚存差异。完整视觉和交互匹配是验收目标，不是 Skill 文件本身能保证的结果。
